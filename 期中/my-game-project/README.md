# 遊戲專案開發報告：反應力挑戰賽

## 1. 專案概述
本專案開發了一個簡單的網頁遊戲，目標是訓練並記錄玩家的反應速度，並透過後端 API 將成績持久化儲存於 MongoDB，最後呈現在公開排行榜中。

## 2. 技術架構
* **前端**: Next.js (React) - 負責遊戲邏輯與 UI 呈現
* **後端**: Node.js + Express - 負責 API 路由與資料庫溝通
* **資料庫**: MongoDB - 儲存玩家暱稱與分數

## 3. API 接口說明
| 方法 | 路徑 | 功能 |
| :--- | :--- | :--- |
| GET | `/api/scores` | 獲取排行榜前 10 名數據 |
| POST | `/api/scores` | 提交新成績 (Body: {username, score}) |

## 4. 開發心得
在此專案中，我學習到如何處理前端與後端的跨域請求 (CORS)，以及如何設計資料庫的 Schema 來儲存時間序列數據。最困難的部分是處理非同步的 API 請求，我透過 async/await 語法成功解決了這個問題。

## 5. 未來優化
